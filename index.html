CLI-Calculator

Open-source, modern C++ command-line calculator

🚀 Installation

git clone https://github.com/Benedek553/cli-calculator
cd cli-calculator
mkdir build && cd build
cmake ..
make
./cli-calculator

💡 Main Features

  • Fast arithmetic operations
  • Decimal, binary, hexadecimal conversions
  • Clean C++ implementation
  • Active development with frequent updates

🔧 Usage Examples

$ cli-calculator --add 120 44
= 164

$ cli-calculator --hex 255
= 0xFF
