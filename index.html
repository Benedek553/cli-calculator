BATCH SCRIPTING

A small language for repetitive math.

Batch files run a list of commands with directives for state and control flow — @set, @input, @include, @if, @unset — so a calculation you'd otherwise repeat by hand becomes a file you run.

Numerical flags accept variable names as arguments, so a batch run can hand its results straight to the next command.

1// tasks.txt
2@set rate = 1.0725
3@input principal "Starting amount:"
4@if principal > 0
5  principal * rate
6@include compound-steps.txt
7@unset rate
$ cli-calculator --batch tasks.txt --output json

FOR WHEN YOU WANT TABS

The same engine, wrapped in a Qt GUI.

Same calculation core, different surface: tabs for expressions, numbers, conversions, equations, matrices, graphs, statistics, variables, and notes, plus an in-app terminal for when you want the CLI back.

  • Split view — open any two tabs side-by-side
  • Notes tab with a Markdown editor, live preview, and LaTeX-style symbols
  • Graphs tab generates PNGs from values or a CSV, saved anywhere on disk
  • An in-app terminal runs CLI calculator commands or shell commands from the workspace directory
