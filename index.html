Features

  • Evaluate complex expressions with trig/log/sqrt and factorial.
  • Binary ⇆ Decimal ⇆ Hexadecimal conversions with sign support.
  • Divisor calculation for any integer.
  • Equation solving (linear, quadratic, complex roots handled).
  • Interactive or one-shot CLI mode.
  • ANSI color output (optional --no-color flag).

Installation

sudo snap install cli-calculator cli-calculator

Build from source

cmake -S . -B build cmake --build build --config Release ./build/src/calculator

CLI Examples

# Convert decimal 78 → hex cli-calculator --convert 10 16 78 # → 0x4E # Evaluate an expression cli-calculator --eval "sin(0.5) + exp(1)" # Divisors of 120 cli-calculator --divisors 120
